# SAIF AI - Mobile Coding Agent & Harness

**SAIF AI** is an advanced on-device AI coding agent and developer harness for Android. Cloned and optimized with 100% feature parity, zero DRM restrictions, and full offline/standalone capability.

## Key Features & Capabilities
- **Local & Remote LLM Engine**: Seamlessly switch between Anthropic, OpenAI, Meta, Kimi, and custom local backends.
- **Full Autonomous Coding Agent**:
  - `ReadTool`, `WriteTool`, `EditTool`, `PatchTool`, `GlobTool`, `GrepTool`
  - `DiagnosticsTool`, `ShellTool`, `QuestionTool`, `TaskTool`, `TodoTool`
  - `WebFetchTool`, `WebSearchTool`
- **MCP (Model Context Protocol)**: Full MCP client manager with OAuth support, tool discovery, and dynamic integration.
- **Skills System**: Interactive skills engine (`code-review`, `skill-creator`, `spike`, `systematic-debugging`, `port-from-project`).
- **Real-Time Voice Announcer**: Text-to-speech task execution announcements.
- **Jetpack Compose UI**: Modern Material 3 interface, syntax-highlighted code editor, diff viewers, and session history.
- **100% DRM-Free**: Standalone execution without Google Play license lockouts.

## Download & Installation
- **Built APK**: `ci/SAIF-AI-debug.apk` (Cryptographically signed v1/v2/v3)
- **Minimum Android**: Android 7.0+ (API 24+)
- **Target Android**: Android 16 (API 36)
